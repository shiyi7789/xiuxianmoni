fix: 连接脚本自动处理远程已存在不相干提交的情况

问题：建仓库时若勾选 "Add a README file"，GitHub 会生成一个与本地历史不相干的
Initial commit，导致 git push 被拒，仓库里只剩 README.md，看起来像"什么都没推上去"。

- connect-github.ps1 现在会先探测远程状态，分四种情况处理：
  远程无 main → 直接推送；与本地一致 → 跳过；同源 → rebase 后推送；
  **不相干历史 → 列出远程占位提交并询问确认，再用 --force-with-lease 覆盖**
- 覆盖前显式打印远程那个提交的内容（--stat），并说明它没有实际价值
- 新增 -Force 开关用于跳过确认
- 远程不可达时输出 git 的原始错误，而不是只给一份通用原因清单
- 部署指引：把"不要勾初始化选项"提为醒目告警并解释症状与补救；
  排错表新增该现象（推送后仓库只有一个 README.md）
