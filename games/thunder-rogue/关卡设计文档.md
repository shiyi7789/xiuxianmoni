# 《星际裂隙 · ROGUE THUNDER》关卡设计文档

版本 1.0 · 竖屏弹幕 Roguelite · 逻辑分辨率 540 × 960（9:16）

---

## 1. 核心意图（Intent）

**玩家幻想**：从一艘火力孱弱的截击机，在两个 Boss 周期内滚成一座移动的火力要塞。玩家感受到的核心快感是**"成长曲线的暴走感"**——每一波敌人被清空时，屏幕上同时亮起三张升级卡，你亲手决定这局要塞长什么样。

**情感弧线**：
> 谨慎求生 → 火力初成（爽） → 弹幕压迫（紧张） → Boss 高压检阅（释放性爆发） → 递归重来

**核心机制教学（无文本空间教学）**：
| 波次 | 教会玩家什么 | 用什么教 |
|---|---|---|
| 1 | 移动 + 自动开火 | 直线下落的 `drone`，密度极低，不还手 |
| 2 | 弹道预判躲避 | `zig` 正弦走位，逼玩家读弹道 |
| 3 | 目标优先级 | 两台 `shooter` 在角落输出，不打就得一直躲 |
| 4 | 空间解题 | `wall` 阵型——一堵敌墙带移动缺口 |
| 5 | 阶段读条 | BOSS-1 三阶段，每阶段前有蓄力预警 |
| 6+ | 组合压力 | 上述元素叠加，新原型逐个空降 |

**必须被记住的一刻**：第 5 波 Boss 被击破时，全场敌人弹幕被冲击波清空、屏幕白闪、百万粒子炸开——玩家的引擎轰鸣声第一次盖过背景音。

## 2. 节奏曲线（Pacing Chart）

单波平均 22–35 秒，波间强制 1.6 秒喘息（Experience Vacuum）。

| 波次 | 活动类型 | 张力 | 设计说明 |
|---|---|---|---|
| 1 | 清理 / 教学 | ▁▂ | 6 只 drone，几乎无失败可能 |
| 2 | 走位教学 | ▁▃ | zig 正弦，逼出横向位移意识 |
| 3 | 定向火力 | ▂▄ | shooter 落位后持续瞄准射击 |
| 4 | 空间解题 | ▃▄ | wall 阵型 + 缺口移动 |
| **5** | **BOSS-1** | ▆█ | 三阶段，弹幕形态切换 |
| 6–7 | 清空 + 新原型 | ▃▃ | chaser / splitter 首次登场 |
| 8–9 | 多线压迫 | ▅▆ | 角落 turret + 正面冲锋 |
| **10** | **BOSS-2** | ▇█ | 螺旋弹幕 + 召唤护卫 |
| 11–14 | 综合考验 | ▆▇ | 全原型混编，波次时长上扬 |
| **15+** | **递归 Boss** | ██ | 每 5 波一个 Boss，HP 与弹速递归放大 |

**呼吸窗设计**：每波结束的 1.6 秒内，所有 XP 晶体自动被吸附、玩家舰体轻微回血（每 3 波 +8%），并播放"波次清除"横幅。这是玩家从紧张回到掌控的锚点，也是升级三选一的情绪落点。

## 4. 阵型库（Formation Library）

阵型是"句子"，波次是"段落"。每个阵型保证**至少两条可执行路线**。

| 阵型 | 形状 | 战术意图 | 玩家可选路线 |
|---|---|---|---|
| `line` | 横向等差下线 | 基础压力 | 侧翼绕射 / 中央强穿 |
| `v` | V 字俯冲 | 中心集中 | 走 V 外侧 / 硬吃中央靠 DPS |
| `arc` | 弧形散开 | 覆盖宽度 | 贴边躲 / 用穿透武器扫线 |
| `stream` | 单列快速流 | **DPS 检测** | 站桩对射 / 侧向错位逐个清 |
| `pincer` | 左右夹击，中央留缝 | 逼迫走中 | 中央收束 / 单侧撕开 |
| `swarm` | 随机散布 | 混乱感 | 交给 AOE / 一个个点 |
| `wall` | 整排敌墙 + 移动缺口 | **空间解题** | 追缺口 / 破墙硬穿 |
| `turrets` | 两角哨塔 + 中央护卫 | 目标优先级 | 先拔塔 / 先清护卫换空间 |
| `spiral` | 螺旋放出的环刃 | 时间压力 | 绕外圈 / 直插中心 |
| `boss` | 单体重型 + 护卫 | 阶段读条 | 贴身抢输出 / 拉开避弹幕 |

**阵型节奏配方**：`简单阵 ×2 → 复合阵 ×1 → 定向压力 ×1 → 呼吸波（低密度）`

## 5. Boss 分阶段设计

### BOSS-1「裂隙哨兵」（第 5 波）
| 阶段 | HP 区间 | 弹幕形态 | 读条 |
|---|---|---|---|
| P1 | 100–70% | **扇形散射**：5→9 发扇形，中心留安全缝 | 0.8s 核心亮红 |
| P2 | 70–35% | **追踪爆裂**：三连瞄准弹 + 侧向散射 | 0.8s 核心亮橙 |
| P3 | 35–0% | **旋转弹幕**：双螺旋连续旋转 | 0.8s 核心亮紫 |
| 附加 | — | 每 8s 召唤 3 只 `drone` 护卫 | — |

### BOSS-2「裂隙核心」（第 10 波）
在 BOSS-1 基础上追加：
- **激光扫射**：先亮 1.2s 预警线，再横扫 0.9s
- **护卫召唤**升级为 `chaser` + `turret` 组合
- 弹幕发数 +60%，冷却 −25%

### 递归 Boss（第 15、20、25… 波）
每轮 HP +55%、弹速 +8%、阶段切换阈值提高。Boss 名号按 `裂隙核心 · 迭代 N` 递进，让玩家的成长曲线在数字上被"偿还"。

## 6. 肉鸽升级系统（Build Crafting）

升级卡分三系，每次升级三选一，稀有度权重 `普通 100 / 稀有 45 / 史诗 18`，受"幸运"属性加成。

### 武器系（8 条 Build 主轴）
| 武器 | 定位 | 成长方式 |
|---|---|---|
| 主炮 | 通用直射，一切 Build 的底座 | 弹丸数 + 伤害 |
| 贯穿激光 | 细长高速穿透，扫线利器 | 穿透层数 + 伤害 |
| 散射炮 | 近距离爆发，清 swarm | 扇面宽度 + 弹丸数 |
| 追踪导弹 | 自动索敌，弥补操作 | 齐射数 + 转向速率 |
| 环绕无人机 | 贴身护卫，接触伤害 + 自动开火 | 数量 + 射速 |
| 电弧链 | 弹射连锁，专治密集阵 | 链数 + 伤害衰减降低 |
| 回旋飞刃 | 去而复返，二次伤害 | 数量 + 折返距离 |
| 引力黑洞 | 聚怪 + 持续伤害，AOE 核心 | 半径 + 牵引力 + 持续 |

武器之间**刻意保留协同**：黑洞的聚怪放大散射炮与电弧链的收益，无人机为黑洞提供近身保护，形成"发现组合"的乐趣。

### 被动系（15 条）
攻击力 / 射速 / 移速 / 最大生命 / 弹速 / 穿透 / 暴击率 / 暴击伤害 / 拾取范围 / 幸运 / 经验获取 / 生命回复 / 能量护盾 / 抗撞击装甲 / 多重射击

### 主动系（3 条）
- **相位冲刺**（Space）：0.35s 无敌位移，冷却 6s → 4.4s
- **湮灭核弹**（Q）：清空全场敌弹 + 全域巨额伤害，携带次数制
- **时间畸变**（E）：3s 内敌方时间流速降至 35%，玩家不受影响

### 兜底规则
当可选项不足 3 张（全满级）时，注入「应急修复（回血 35%）」与「过载校准（全属性 +6%，可无限叠加）」，保证三选一永不卡死。

## 7. 可读性检查表（上线前自检）

**关键路径**
- [x] 敌弹使用高饱和暖色（粉/橙/黄），玩家弹使用冷色（青/蓝），色彩语义 100% 分离且不重叠
- [x] 玩家舰体永远带 6px 光晕 + 引擎尾焰，在密集弹幕中可被视觉锁定
- [x] Xp 晶体带拖尾 + 吸附加速，永远不会被误认为敌弹
- [x] 敌弹与玩家弹尺寸差异 ≥ 2px，即使在最密弹幕中也能区分

**战斗可读性**
- [x] 所有 `shooter` / `turret` 开火前有 0.45s 炮口充能闪光（预警）
- [x] Boss 每次切换阶段有 0.8s 核心变色蓄力，无瞬发无预警伤害
- [x] 玩家受击有 0.9s 无敌闪烁 + 屏幕红闪 + 震动，绝无"莫名死亡"
- [x] 屏幕震动设上限（14px），不干扰弹幕判读

**Explore 选项提示**
- [x] 拾取物按颜色分类：青=经验 红=生命 蓝=护盾 黄=核弹
- [x] 掉落物带脉冲光晕，在弹幕中依然可辨识
